# GEC1044 TCM Project Exploration Guide

This folder collects study notes, fieldwork materials, research references, report drafts, and exploratory models for a Traditional Chinese Medicine (TCM) project. Use it to understand possible topics, trace sources, and develop your own research question and analysis.

> **For reference only. Plagiarism is strictly banned.** Do not submit, copy, translate, or lightly paraphrase these reports, previous teams' work, diagrams, code outputs, or other materials as your own. Acknowledge ideas and assistance, cite original sources, and follow your course's academic integrity and AI-use requirements. Referencing this repository does not replace citing the underlying sources.

## Start here

1. Read [the assessment notes](GEC1044_Canvas_Assessment.md) to understand the recorded project context. Check the current official course brief for requirements and deadlines.
2. Open [the lecture archive guide](Lecture%20Document/START_HERE.md), then read [the Lectures 1–12 study notes](Lecture%20Document/GEC1044_Lectures_1-12_Study_Notes.md). Use the source index to check concepts against the original materials.
3. Browse the fieldwork and reference folders below. Record each source's author, title, date, and relevant page before using it.
4. Choose your own focused question, such as how a dietary practice is understood in TCM, how it is used locally, or how traditional explanations compare with published research.
5. Inspect the report outline, drafts, and final PDF to learn about structure and revision. Develop your own argument, evidence, wording, and figures.
6. If exploring systems thinking, start with [the simulation guide](Model%20Simulation/README.md) and its linked latest model. Check assumptions, parameter sources, and limitations before interpreting any output.

## Use the material critically

Distinguish traditional TCM theory, fieldwork observations, published empirical findings, and model assumptions in your writing. Follow references back to primary sources and verify quotations, translations, numerical claims, and bibliographic details. Simulated changes are illustrative model outputs; they do not establish clinical efficacy or predict an individual's health. These materials are educational references, not medical advice.

Markdown files can be read directly on GitHub or in a text editor. Open PDFs with a PDF reader and DOCX files with Word or a compatible editor. Python scripts and Stella files are optional exploration tools; consult their local documentation and inspect scripts before running them. Some historical scripts contain paths from the original author's computer.
